| 项 | URL |
|----|-----|

| 在线预览 | https://template.tyjz.com/14525/ |

预览以 iframe 嵌入 `https://template.tyjz.com/14525/`，支持桌面 / 平板 / 手机外框切换（上架页 `pc0/pc1`、`pb0/pb1`、`sj0/sj1` 仅为设备图标，不是设计稿）。

## 技术栈（模板原站）

- jQuery 3.5.1  
- Swiper + swiper.animate  
- WOW.js（滚动入场）  
- SuperSlide  
- waypoints + countup（数字滚动）  
- Font Awesome  
- 多页 `.aspx`（CMS 型）

**实现本站时不要整站 fork**；只借 IA 与区块节奏，用现代静态栈重做。

## 导航结构（原站）

```

```

映射到本站见 [../sitemap.md](../sitemap.md)。

## 首页区块顺序（原站）

1. 顶栏 + 移动抽屉  
2. `banner_swiper`：全幅图 +「WELCOME！」+ 副标题 +「我的作品」  
3. 引言：「跨越领域，融合创新…」  
4. 个人简介 + 配图 +「了解更多」  
5. 四宫格：专业技能 / 兴趣爱好 / 能力荣誉 / 教育背景  
6. 数字条：如「120+ 负责过的项目」（count-up）  
7. 多领域作品网格 +「查看更多案例」  
8. 项目经验 / 新闻列表卡  
9. 联系 CTA（电话/邮箱/QQ）+ 页脚  
10. 右侧悬浮：电话 / QQ / 微信  

## 色板采样（style.css，供对比）

模板常见色：

- 背景浅灰：`#EDF1F5`、`#f6f7fc`、`#fafbfd`  
- 强调绿：`#78d1ad`、`#45c88f`  
- 强调橙红：`#f17f6e`、`#e9593f`  
- 蓝紫点缀：`#90c6f3`、`#bab1f2`、`#8f7cff`  
- 正文灰：`#333` / `#666`  
- 字体：`Arial, 'Microsoft YaHei'`

本站**不沿用**上述糖果多色；改用 DESIGN.md 中的青墨 + 冷青 + 暖高光。

## 布局特征

- Hero 左文右（或压字）大图，适合放产品截图  
- 关于区双栏 + 下方四卡  
- 作品多为等比卡片网格  
- 侧浮层适合放联系方式，移动端需改底栏  

## 文案特征（原站占位）

通用创意/摄影口吻（「热爱创新」「多领域综合」）。  
本站全部替换为 CONTENT.md 工程叙事，禁止残留「120+ 项目」等虚假占位数字。

## 可复用交互清单

| 交互 | 复用方式 |
|------|----------|
| Hero 轮播 | Swiper 或轻量自研；6s 自动、可暂停 |
| 数字 count-up | IntersectionObserver + 自研计数 |
| 滚动入场 | CSS `@keyframes` + `prefers-reduced-motion` |
| 侧浮联系 | 自研组件；微信用二维码弹层 |
